01

Алгоритм і програма

▸

Вам потрібно навчити робота робити бутерброд зі згущеним молоком. Ваші інструкції можуть бути приблизно такими:

Для робота — програма
  • Відкрити нижні праві дверцята шафи.
  • Взяти банку зі згущеним молоком і вийняти її з шафи.
  • Закрити шафу.
  • Тримаючи банку в лівій руці, взяти кришку в праву руку.
  • Повертати праву руку проти годинникової стрілки, доки кришка не відкриється.
  • І так далі…
Для людини — алгоритм
  • Дістаньте згущене молоко і хліб.
  • Намажте ножем або ложкою згущене молоко на одну скибочку хліба.
  • Смачного!

Перше — це програма: ви описали кожен крок, який комп'ютер повинен виконати, і вказали всю інформацію, яка потрібна для виконання кожного кроку. Друге — це алгоритм: процес, якому потрібно слідувати для отримання бажаного результату. Зверніть увагу, що алгоритм більш узагальнений, ніж програма.

Програма повідомляє роботу, звідки саме потрібно взяти предмети на конкретній кухні, з точною вказівкою всіх необхідних деталей. Це реалізація алгоритму, яка надає всі важливі деталі, але може бути виконана на будь-якому устаткуванні (в даному випадку — на кухні), з усіма необхідними елементами.

Алгоритм — набір інструкцій, що описують порядок дій виконавця для досягнення результату розв'язання задачі за кінцеве число дій.

Основні алгоритмічні структури

Алгоритми бувають:

  • Лінійні — набір команд (вказівок), які виконуються послідовно в часі одна за одною.
  • Розгалужувані — алгоритм, що містить хоча б одну умову, в результаті перевірки якої може здійснюватися поділ на кілька паралельних гілок алгоритму.
  • Циклічні — алгоритм, що передбачає багаторазове повторення однієї й тієї ж дії над новими вихідними даними. До циклічних алгоритмів зводиться більшість методів обчислень, перебору варіантів.
  • Змішані — поєднання кількох видів алгоритмів.

Лінійний алгоритм — набір команд (вказівок), що виконуються послідовно в часі одна за одною.

Алгоритм, що розгалужується — алгоритм, що містить хоча б одну умову, в результаті перевірки якої може здійснюватися поділ на кілька паралельних гілок алгоритму.

Тобто алгоритм, що розгалужується, містить умови, в залежності від яких виконується одна або інша послідовність дій. Кожна з них, у свою чергу, також може (але не зобов'язана) мати розгалуження.

Приклад з реального життя: якщо надворі дощ → бери парасолю, інакше → не бери.
02

Простий if

▸

Конструкція if у Python — це умовна команда, яка дозволяє програмі приймати рішення: виконувати певні дії лише тоді, коли умова є істинною (True).

if умова:
    оператори

Тут: умова — це логічний вираз, оператори — це послідовність будь-яких інших команд.

Блок операторів не може бути порожнім. Якщо така необхідність виникає, можна скористатися оператором pass, який нічого не робить.

Синтаксис — найважливіше: двокрапка після умови, відступ 4 пробіли.

04

Оператор pass

▸

Якщо блок порожній — Python вимагає хоч щось. Для цього є pass.

Для чого pass використовують на практиці

  • Коли умова є, але дії поки не потрібні
  • Коли пишуть структуру програми наперед

Іноді програмісти спочатку роблять «скелет» програми, а код додають пізніше.

05

if / else — два варіанти

▸ 
if умова:
    блок_операторів_1
else:
    блок_операторів_2

Тут, якщо умова є істинною, виконуються оператори з першого блоку, інакше — з другого.

07

Вкладені if та if/elif/else

▸

Коли гілок більше двох — elif читабельніший за вкладені if:

❌ Без elif (погано виглядає)
if y < 0:
    print('негативне')
else:
    if y > 0:
        print('позитивне')
    else:
        print('нуль')
✅ З elif (чисто)
if y < 0:
    print('негативне')
elif y > 0:
    print('позитивне')
else:
    print('нуль')
08

Каскадування операторів розгалуження

▸

Часто виникає необхідність по черзі перевірити кілька умов (найчастіше — рівність якогось виразу певним значенням). Однак величезна кількість (каскад) вкладених умовних операторів виглядає нечитабельною, і при написанні такого коду легко припуститися помилки.

Практика

▸
1Парне чи непарне⭐
Запитай число. Виведи «парне» або «непарне».
2Перевірка віку⭐
Запитай вік. Якщо < 6 → «дитина», < 18 → «підліток», < 60 → «дорослий», інакше → «пенсіонер». Використай elif.
3Додатнє / від'ємне / нуль⭐
Користувач вводить ціле число. Виведи: positive, negative або zero.
4Більше з двох⭐
Зчитати два числа і вивести більше (якщо рівні — вивести будь-яке та підпис «рівні»).
5Лід, рідина чи пара⭐
≤0 — лід, ≥100 — пара, інакше — рідина.
6Належність діапазону⭐⭐
Вкажи, чи належить число закритому діапазону [1; 10].
7Від'ємне → додатне⭐⭐
Перетвори від'ємне число на додатне за допомогою if.
8Калькулятор операцій⭐⭐
Виведи меню: 1-додавання, 2-віднімання, 3-множення, 4-ділення. Запитай два числа та номер операції, виведи результат. При діленні на 0 — попередження.
9Впізнай мене⭐
Напишіть програму, яка запитує у користувача його ім'я, і якщо воно збігається з вашим — видає певне повідомлення.
