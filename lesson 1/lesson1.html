Python-середовище: очікує запуску
01

Visual Studio Code для Python

▸
  1. Встанови Python (python.org). Постав галочку Add to PATH.
  2. Встанови VS Code (Win/Mac/Linux).
  3. Відкрий проєкт у VS Code (File → Open Folder...), створи main.py.
  4. Extensions → Python (Microsoft) → Install.
  5. Ctrl+Shift+P → Python: Select Interpreter → Python 3.x (64-bit).
  6. Запуск: кнопка ▶ або термінал: python main.py (Windows: py main.py).
02

Ідентифікатори

▸

Ідентифікатор — це ім'я, за яким можна звертатися до будь-якого об'єкта. Він може складатися з великих і маленьких букв, цифр, знаків підкреслення.

⚠️ Не повинен починатися з цифри і не може збігатися із зарезервованими ключовими словами: False, class, finally, is, return, None, continue, for, lambda, try, True, def, from, nonlocal, while, and, del, global, not, with, as, elif, if, or, yield, assert, else, import, pass, break, except, in, raise.

None — спеціальне значення типу NoneType, яке використовується, щоб вказати на відсутність значення.

03

Типи даних

▸
  • int — тип даних, який використовується для цілих чисел. Приклади: 3; 0; 25612346252
  • bool — логічні значення. Використовується для перевірки істинності якоїсь умови. Якщо умова вірна — True, інакше — False.
  • float — дійсні числа подвійної точності. Приклади: 0.3215235, 125256.73
  • complex — комплексні числа. Приклади: 2+3j, 0.7 - 0.1j
  • str — незмінна послідовність символів; "string" — "рядок".

print()

Виводить текст у консоль. Кожен print закінчується новим рядком.

Як працює print(): коми та лапки

  • Лапки "…" або '…' — це рядок (текст-букви). Те, що в лапках, друкується як є: print("Привіт").
  • Без лапок — це змінні або вирази, які спершу обчислюються: a = 5, print(a) → покаже 5, а не букву «a».
  • Кома в print розділяє частини і автоматично ставить пробіл між ними: print("Сума:", 2+3) → Сума: 5.
  • Плюс + з'єднує саме рядки: "Привіт, " + name. Якщо зліва текст, а справа число — треба перетворити: str(число).
  • F-рядки (зручно!): name="Іра"; print(f"Привіт, {name}") — вставляє значення прямо в текст.
04

Введення та перетворення типів

▸

Для введення даних із клавіатури використовується функція input(). Результат цієї функції завжди є рядком (str).
