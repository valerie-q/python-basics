01

Truth Value Testing

▸

В Python будь-яке значення можна використати як True або False — не тільки bool.

❌ Вважаються False:
None, False, 0, 0.0, 0j, '' (порожній рядок), [], {}, ()
Все інше — вважається True.

Навіщо це потрібно? Дозволяє писати коротший і читабельніший код:

# Довгий варіант:
if string is not None and string != '':
    num = int(string)

# Короткий варіант (те саме!):
if string:  # перевіряє чи змінна string не false
    num = int(string)

# Ще приклади:
number = 0
if number:  # False, бо 0
    print('не нуль')

name = 'Андрій'
if name:  # True, бо рядок не порожній
    print('привіт,', name)
💡 Запам'ятай:
if x: → те саме що if x != 0 and x is not None
if not x: → те саме що if x == 0 or x is None or x == ''

Що таке .format()?

У файлі вище є рядок 'The string is {}'.format(string). Це спосіб вставити значення змінних у текст: у рядку ставимо {} як порожні місця, а в дужках після .format перераховуємо, що туди підставити.

F-рядок і .format() роблять одне й те саме. F-рядок коротший, тому зараз зазвичай пишуть так, а .format() часто зустрічається в чужому коді.
02

Тернарний оператор (умовний вираз)

▸

Досить часто виникає ситуація, коли нам потрібно використовувати той чи інший вираз в залежності від певної умови. У Python існує конструкція, яка за своєю дією аналогічна конструкції if-else, але при цьому є умовним виразом.

Тернарний оператор — це скорочений спосіб записати if/else в одному рядку. Він єдиний в Python, що потребує три операнди: що повернути, умова, що якщо ні.

Синтаксис:
вираз_якщо_True if умова else вираз_якщо_False

Порівняй два варіанти — вони роблять одне і те саме:

⚠️ Коли НЕ варто використовувати тернарний:
Якщо вираз стає занадто довгим або заплутаним — краще звичайний if/else. 
# Погано — важко читати:
x = 'A' if a > b else 'B' if b > c else 'C'
03

Складні умови: and, or, not

▸

Іноді одна умова недостатня — потрібно перевірити кілька речей одразу.

and — обидві умови мають бути True

or — достатньо однієї умови

not — заперечення умови

Пріоритет операторів

Важливо знати порядок виконання: not → and → or

# not виконується першим:
if not a and b:       # (not a) and b

# and виконується перед or:
if a or b and c:      # a or (b and c)

# Для зрозумілості — завжди використовуй дужки!
if (age >= 18 and has_id) or is_vip:
    print('дозволено')

⭐ Практика — Рівень 1 (truth value + тернарний)

▸
1Порожній рядок⭐
Запитай ім'я користувача. Якщо він нічого не ввів (порожній рядок) — виведи «Ім'я не вказано», інакше — «Привіт, [ім'я]!». Використай truth value (не порівнюй з '').

💡 if name: — те саме що if name != '' and name is not None

2Нульова оцінка⭐
Запитай оцінку (число). Виведи «оцінка є» або «оцінка відсутня» — використай truth value. Підказка: 0 вважається False.

💡 Якщо score = 0 → False, якщо будь-яке інше число → True

3Модуль числа⭐
Запитай число. Виведи його модуль (без від'ємного знаку). Використай тернарний оператор в одному рядку.

💡 Якщо число >= 0 → залишаємо як є, інакше → множимо на -1

4Більше чи менше⭐
Запитай два числа a і b. Одним рядком (тернарний) виведи: «a більше», «b більше» або «рівні».

💡 Вкладений тернарний: спочатку перевіряємо a > b, потім b > a, інакше рівні

5Парне / непарне (тернарний)⭐
Запитай число. Одним рядком через тернарний оператор виведи «парне» або «непарне».

💡 % 2 == 0 → ділиться на 2 без остачі → парне

05

⭐⭐ Практика — Рівень 2 (and, or, not)

▸
6Вхід у систему⭐⭐
Задай у коді логін = 'admin' і пароль = '1234'. Запитай логін і пароль у користувача. Використай and: якщо обидва збігаються — «Вхід успішний», інакше — «Невірні дані».

💡 and — обидві умови мають бути True одночасно

7Вихідний день⭐⭐
Запитай день тижня. Якщо «субота» або «неділя» — виведи «Вихідний, відпочиваємо!», інакше — «Робочий день, до справ!»

💡 .lower() — щоб не залежати від регістру вводу

8Допуск до іспиту⭐⭐
Запитай кількість відвідувань (з 10) та середній бал (1-12). Студент допускається до іспиту якщо: відвідувань >= 7 і бал >= 4. Виведи відповідне повідомлення та причину недопущення.

💡 Бонус: виводимо причину відмови — корисно для користувача

9Знижка у магазині⭐⭐
Запитай вік та чи є студентський квиток ('так'/'ні'). Ціна товару = 500 грн.
• Якщо вік < 18 або є студентський → знижка 20%
• Якщо вік > 60 → знижка 30%
• Інакше → повна ціна. Виведи фінальну ціну.

💡 Перевіряємо вік > 60 першим, бо ця знижка більша

⭐⭐⭐ Практика — Рівень 3 (комбіновані задачі)

▸
10Класифікатор оцінок⭐⭐
Запитай оцінку (1–12). Виведи: 10–12 → «Відмінно», 7–9 → «Добре», 4–6 → «Задовільно», 1–3 → «Незадовільно», інше → «Некоректна оцінка». Використай and для перевірки діапазону та коротший запис діапазону.

💡 Python дозволяє 10 <= score <= 12 замість score >= 10 and score <= 12

11Вікторина на 3 питання⭐⭐⭐
Задай 3 питання з варіантами відповіді. Підраховуй бали за правильні. Наприкінці виведи результат: 3/3 → «Відмінно!», 2/3 → «Добре!», 1/3 → «Спробуй ще», 0/3 → «Готуйся краще». Використай тернарний оператор хоча б для одного повідомлення.

💡 Тернарний використано для розрізнення score == 1 та score == 0

12Перепиши калькулятор⭐⭐⭐
Візьми калькулятор з Уроку 1. Перепиши перевірку ділення на 0 за допомогою тернарного оператора. Додай перевірку: якщо користувач не ввів число (порожній рядок) — виведи «Помилка вводу» (truth value).

💡 if not a_str — truth value: порожній рядок = False, not False = True

📋 Коротко

▸

  • Тернарний оператор: значення_if_true if умова else значення_if_false

  • or — хоча б одна True
  • not — заперечення

Додаткові завдання

▸
1Високосний рік⭐⭐
Рік є високосним якщо він складається з 366 днів (а не 365). Рік є високосним якщо: ділиться на 4, але не на 100 — або ділиться на 400. Напиши програму, яка запитує рік і виводить leap year або not a leap year.

💡 Перевіряємо від загального до конкретного: спочатку % 4, потім % 100, потім % 400. Другий варіант (вкладка «бонус») — коротший запис через and/or.

2Дивне число⭐⭐
Дано ціле число n. Якщо n непарне → виведи Weird. Якщо n парне і в діапазоні [2, 5] → виведи Not Weird. Якщо n парне і в діапазоні [6, 20] → виведи Weird. Якщо n парне і більше 20 → виведи Not Weird.

💡 Спочатку відсіюємо непарні, потім для парних перевіряємо діапазон

3FizzBuzz⭐⭐
Дано число n. Виведи: FizzBuzz — якщо ділиться і на 3, і на 5; Fizz — якщо ділиться тільки на 3; Buzz — якщо ділиться тільки на 5; саме число — якщо не ділиться ні на 3, ні на 5. Увага: найспецифічнішу умову (і 3, і 5) перевіряємо ПЕРШОЮ!

💡 Якщо поставити FizzBuzz після Fizz/Buzz — воно ніколи не спрацює, бо elif вже зупиниться раніше

5Класифікатор оцінок (100-бальна шкала)⭐⭐
Прийми оцінку (0–100) і виведи літерну оцінку: 90–100 → A, 80–89 → B, 70–79 → C, 60–69 → D, нижче 60 → F. Якщо введено число не в діапазоні 0–100 → виведи повідомлення про помилку.

💡 Перевіряємо від найвищого до найнижчого — кожен elif спрацьовує тільки якщо попередні не спрацювали

6Текстовий квест⭐⭐⭐
Створи коротку текстову пригоду. Гравець робить вибір у різних точках, а вкладені if-else визначають результат. Мінімум 3 рівні вибору, 2+ кінцівки. Використай if/elif/else або match/case.

💡 Кожен рівень — це новий вкладений if. Завжди додавай else для некоректного вводу

7Відпустка програміста⭐⭐⭐
Програма приймає бюджет і сезон, виводить місце відпустки і суму витрат. До 100$ → Болгарія: літо — 30%, зима — 70% бюджету. До 1000$ → Балкани: літо — 40%, зима — 80% бюджету. Більше 1000$ → Європа: завжди готель, 90% бюджету.

💡 В Європі сезон не впливає — вкладений if не потрібен

8Калькулятор ІМТ⭐⭐
Запитай вагу (кг) і зріст (м). Обчисли ІМТ = вага / (зріст²). Виведи категорію: <18.5 → Недостатня вага, 18.5–24.9 → Нормальна вага, 25–29.9 → Надлишкова вага, 30 і більше → Ожиріння.

💡 height ** 2 — зріст у квадраті. :.1f — виводимо з одним знаком після коми

9Час доби⭐
Запитай годину (0–23). Виведи частину доби: 6–11 → Доброго ранку!, 12–17 → Добрий день!, 18–21 → Добрий вечір!, 22–23 або 0–5 → Добраніч! Якщо введено число не в діапазоні 0–23 → повідомлення про помилку.

💡 else в кінці охоплює і нічні години після 22, і ранні до 6 — не потрібно писати дві умови

10Ціна квитка на атракціон⭐⭐
Базова ціна квитка — 200 грн. Вік <5 або >70 → безкоштовно. Вік 5–12 → знижка 50%. Вік 13–17 або >60 → знижка 25%. Якщо є пільгове посвідчення → додаткова знижка 10% (від вже зниженої ціни).

💡 Знижку за посвідчення рахуємо окремим if після основного — щоб вона застосувалась до вже зниженої ціни
