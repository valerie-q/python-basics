01

Що таке match/case

▸

match/case — нова конструкція Python 3.10+, яка замінює довгі ланцюжки if/elif/else, коли потрібно порівнювати одну змінну з багатьма значеннями.

Синтаксис

match змінна:
    case значення_1:
        # дії якщо змінна == значення_1
    case значення_2:
        # дії якщо змінна == значення_2
    case _:           # _ — це default, виконується якщо нічого не збіглось
        # дії за замовчуванням
⚠️ Тільки Python 3.10+ — на старіших версіях match/case не працює!
02

if/elif vs match/case

▸

Ці два варіанти роблять одне і те саме. Перемикай вкладки й запускай обидва:

Ключові відмінності match/case від if/elif:
  • | замість or — для кількох значень в одному case
  • case _ — замість else (default, якщо нічого не збіглось)
  • Немає and/or для складних умов — для цього краще if
  • Тільки Python 3.10+

04

Бонус: match зі списком

▸

match/case вміє розпізнавати й структуру даних — наприклад, список з різною кількістю елементів:

💡 case [name, age]: спрацьовує тільки якщо введено рівно 2 слова
05

Практика

▸

⭐ Рівень 1

1Знак числа⭐
Запитай число. Використай match/case, щоб вивести:
  • число > 0 → «Додатнє»
  • число < 0 → «Від'ємне»
  • число == 0 → «Нуль»
match/case не вміє порівнювати діапазони — використай if для визначення знаку, а потім match для виводу повідомлення.
Або спробуй match з guard (if після case).

💡 case n if n > 0: — це guard (охоронець), дозволяє додати умову всередині case

2Повний тиждень⭐
Запитай день тижня. Виведи повідомлення для кожного дня.
Суботу та неділю об'єднай в одному case через |.

💡 | замість or — тільки в match/case. У звичайному if треба писати or

3Калькулятор на match/case⭐
Запитай два числа і операцію (+, -, *, /). Виконай відповідну дію.
Перевірку ділення на нуль також зроби через match або if.
Для невідомої операції — виведи повідомлення про помилку.

💡 Всередині case можна використовувати звичайний if — вони чудово поєднуються

⭐⭐ Рівень 2

4Квадратне рівняння⭐⭐
Розв'яжи квадратне рівняння ax² + bx + c = 0.
Запитай a, b, c. Обчисли дискримінант D = b² − 4ac.
  • D > 0 → два корені: x1 = (−b + √D) / 2a, x2 = (−b − √D) / 2a
  • D == 0 → один корінь: x = −b / 2a
  • D < 0 → дійсних коренів немає
Використай import math для math.sqrt(). Результат match застосуй для виводу.
math.sqrt() — квадратний корінь. :.2f — округлення до 2 знаків після коми.

💡 math.sqrt() — квадратний корінь. :.2f — округлення до 2 знаків після коми

5Класифікатор трикутника⭐⭐
Запитай три сторони трикутника (a, b, c).
Спочатку перевір, чи це взагалі трикутник (сума двох сторін > третьої). Потім визнач вид:
  • всі три сторони рівні → рівносторонній
  • рівно дві сторони рівні → рівнобедрений
  • всі різні → різносторонній
Бонус: перевір також, чи він прямокутний (a² + b² == c²).
sorted() сортує список — найменші сторони перші, найбільша остання (гіпотенуза).

💡 sorted() сортує список — найменші сторони перші, найбільша остання (гіпотенуза)

6Сезон року⭐⭐
Запитай місяць (число від 1 до 12). Виведи пору року.
Об'єднай місяці одного сезону через | в одному case.
Додай перевірку: якщо введено число не від 1 до 12 → повідомлення про помилку.
Бонус: також виведи кількість днів у цьому місяці (враховуй лютий — 28 або 29).
Два match поспіль — перший для сезону, другий для кількості днів.

💡 Два match поспіль — перший для сезону, другий для кількості днів

⭐⭐⭐ Рівень 3 — Міні-проєкт на вибір

А🎮 Текстовий квест⭐⭐⭐
Розшир текстовий квест з додаткових завдань або створи новий.

Вимоги:

  • мінімум 4 рівні вибору (глибина)
  • мінімум 3 різні кінцівки (перемога / поразка / секретна)
  • хоча б один match/case для вибору дії
  • підрахунок очок або здоров'я гравця
  • виведи підсумок в кінці
Б🧮 Розумний калькулятор⭐⭐⭐
Створи повноцінний калькулятор з меню і перевірками.

Вимоги:

  • меню з операціями через match/case (+ - * / % // **)
  • перевірка ділення на нуль
  • перевірка від'ємного числа для квадратного кореня (import math)
  • перевірка, що введено саме число (truth value)
  • виведи красиве меню на початку

💡 case '+' | '1': — можна вводити або символ операції, або її номер з меню
