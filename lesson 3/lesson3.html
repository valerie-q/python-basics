Рядки (string, str)

▸

Рядок (string, str) у Python — це послідовність символів, взята в лапки: "Hello", 'ITway', "2025". Символами можуть бути:

  • букви (латиниця, кирилиця тощо);
  • цифри;
  • пробіли, розділові знаки;
  • емодзі 💻🔥🙂.

Регістр і довжина рядка

▸
  • усі великі літери — upper()
  • усі малі — lower()
  • кожне слово з великої — title()
  • довжина рядка — len()

Чому важливо приводити до одного регістру?

Коли користувач вводить текст, він може писати як завгодно: "Yes", "YES", "yes", "yEs"… Для нас усі ці варіанти означають одне і те саме, але для комп'ютера це різне. Тому регістр завжди потрібно нормалізувати.

Unicode

▸

Раніше комп'ютери розуміли тільки числа. Тому кожній букві призначали число. Наприклад, у старому стандарті ASCII: A = 65, B = 66, a = 97.

Але ASCII мав лише 128 символів: англійські літери, цифри, базові символи. Не було українських літер, японських символів, емодзі і т.д.

Unicode — це універсальний стандарт, який призначає унікальний номер кожному символу у світі:

  • A → U+0041
  • Б → U+0411
  • あ → U+3042
  • 😀 → U+1F600

"U+" означає номер символу в таблиці Unicode. Завдяки Unicode текст виглядає однаково на різних пристроях — українська, китайська, арабська — усе працює.

Без Unicode: ламався б текст, замість букв були б "кракозябри", різні системи не розуміли б одна одну.
